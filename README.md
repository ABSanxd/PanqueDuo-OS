# 💻 PanqueDuo-OS

**PanqueDuo-OS** es una experiencia web interactiva que simula un sistema operativo ficticio. Fue desarrollada como un proyecto personal con el objetivo de crear una forma diferente y entretenida de explorar contenido mediante una interfaz inspirada en un escritorio de computadora.

A través de distintos módulos, el usuario puede navegar por archivos, interactuar con una terminal, descubrir pistas ocultas y completar pequeños desafíos.

---

## ✨ Características

- 🖥️ Simulación de un sistema operativo.
- 📂 Explorador de archivos interactivo.
- ⌨️ Terminal con comandos personalizados.
- 🔐 Búsqueda de claves y elementos ocultos.
- 🎮 Minijuegos integrados.
- 🤖 Interacciones dinámicas mediante JavaScript.
- 🎨 Interfaz inspirada en un escritorio de computadora.

---

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## 📁 Estructura del proyecto

```
PanqueDuo-OS/
│
├── assets/         # Recursos gráficos e imágenes
├── drive.js        # Explorador de archivos
├── terminal.js     # Simulación de terminal
├── game.js         # Minijuegos
├── ia.js           # Lógica de interacciones
├── function.js     # Funciones auxiliares
├── word.js         # Palabras, pistas y contenido
├── style.css       # Estilos de la interfaz
└── index.html      # Punto de entrada
```

---

## 🚀 Cómo ejecutar el proyecto

1. Clona el repositorio.

```bash
git clone https://github.com/ABSanxd/PanqueDuo-OS.git
```

2. Abre el archivo `index.html` en tu navegador.

También puedes acceder mediante GitHub Pages

---

## 🎯 Objetivo del proyecto

Este proyecto nació como un regalo personalizado y un ejercicio creativo para experimentar con JavaScript y el desarrollo de interfaces interactivas.

La idea fue recrear la sensación de utilizar un pequeño sistema operativo donde cada ventana, archivo o interacción pudiera esconder algún detalle, pista o sorpresa para el usuario.
